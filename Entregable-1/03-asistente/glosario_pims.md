# Glosario del PIMS para AUDITA-PIMS

| Término | Definición operativa |
|---|---|
| **PIMS** | Sistema de Gestión de Privacidad de la Información. En ISO/IEC 27701:2025 es un sistema de gestión autónomo y certificable, sin requerir ISO 27001. |
| **PII** | Información de identificación personal: cualquier dato que identifica o puede identificar a una persona natural (titular). |
| **Titular (PII principal)** | Persona a la que se refieren los datos. |
| **Responsable del tratamiento (controller)** | Quien decide los fines y medios del tratamiento. Controles del Anexo A, tabla A.1. |
| **Encargado del tratamiento (processor)** | Quien trata PII por cuenta del responsable. Controles de la tabla A.2. |
| **Controles comunes** | Aplican a ambos roles. Tabla A.3. |
| **SoA** | Declaración de Aplicabilidad: lista cada control del Anexo A, si aplica y por qué, y su estado de implementación. |
| **RoPA** | Registro de actividades de tratamiento. |
| **DPIA / EIPD** | Evaluación de impacto en la privacidad, obligatoria para tratamientos de alto riesgo. |
| **DSAR / ARCO** | Solicitudes de los titulares: acceso, rectificación, cancelación/supresión, oposición (y portabilidad). |
| **Evidencia de auditoría** | Registros, declaraciones de hechos u otra información pertinente y verificable relacionada con los criterios de auditoría (ISO 19011). |
| **Criterio de auditoría** | Requisito contra el que se compara la evidencia (cláusula o control). |
| **Hallazgo** | Resultado de comparar la evidencia con el criterio: conformidad, no conformidad mayor/menor, observación u oportunidad de mejora. |
| **SHA-256** | Función hash criptográfica; cualquier cambio de un byte del archivo cambia el valor. Se usa para probar integridad. |
| **Cadena de custodia** | Registro cronológico de quién recolectó, verificó o movió una evidencia. Aquí, cada línea incluye el hash de la anterior, de modo que reescribirla rompe la cadena. |
| **Expediente** | Carpeta con el índice, la cadena de custodia y las copias inmutables de las evidencias. |
| **HITL** | Human-in-the-loop: el asistente propone, una persona aprueba (aquí, el auditor interno o el DPO). |
| **Ley N.º 29733** | Ley de Protección de Datos Personales del Perú; su reglamento es el D.S. N.º 016-2024-JUS. |
